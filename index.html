常見問題

QR Code 可以存放多少資料？
QR Code 最多可存放約 4,296 個字元（英數字）或 1,817 個漢字。建議內容盡量簡短以確保掃描成功率。
容錯等級是什麼意思？
容錯等級決定 QR Code 損壞後仍可讀取的比例。L 為 7%、M 為 15%、Q 為 25%、H 為 30%。等級越高，QR Code 越密集但更耐用。
我的資料會被上傳嗎？
不會。QR Code 完全在您的瀏覽器中產生，資料永遠不會離開您的裝置。
可以下載什麼格式？
支援下載 PNG 圖片格式和 SVG 向量格式。SVG 格式可無限放大不失真。
批量模式最多可以產生幾個？
批量模式最多可一次產生 50 個 QR Code。每行輸入一個文字或網址即可。
CSV 要使用什麼格式？
第一列請使用 name,content。name 是下載檔名，content 是 QR Code 內容；批次資料也能直接下載成相同格式的 CSV。
